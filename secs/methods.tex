\subsubsection{Aurora}
Aurora is Argonne National Laboratory's exascale supercomputer with over 10,000 compute nodes \cite{aurora-intro2025}. Aurora currently has the largest DAOS deployment in production, comprising 1,024 storage nodes \cite{aurora-daos-slingshot-rpc2025cug, io500-ics26}. We were allocated a 100~TB DAOS pool under the \textit{daos\_user} group. Per the Aurora user guide \cite{daos-aurora-guide} and our system queries, this group spans 128\footnote{Only 126--127 nodes were active during the experiments. } storage nodes, each with 16 PMem devices and 2 200Gbps Slingshot-11 Ethernet NICs.

The Aurora supercomputer nodes are interconnected via a large-scale Dragonfly network \cite{aurora-intro2025, daos-aurora-guide}. The 1,024 DAOS server nodes in 64 racks are organized into 8 Dragonfly groups, while compute/client nodes are distributed across 166 groups. This topology enables efficient communication between arbitrary client-server pairs, yet still incurs non-negligible latency due to multi-hop routing. This explains why the bandwidth numbers measured in our experiments are lower than those reported in \cite{DAOS-aurora-20-node-test2024scw}, which is based on the same node specification but a much simpler network topology.


\subsubsection{Our Testbed}
We host a DAOS testbed of 3 storage nodes. Unlike Aurora, this testbed uses DRAM as the first-tier storage and InfiniBand as the interconnect. A single DAOS client node accesses it via a 200~Gbps link. The server and client nodes are connected to the same InfiniBand switch, ensuring low-latency RDMA access.
