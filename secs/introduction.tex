\section{Introduction}

Distributed Asynchronous Object Storage (DAOS) is a high-performance, open-source parallel I/O stack built on Non-Volatile Memory Express (NVMe) and Remote Direct Memory Access (RDMA) technologies \cite{daos-exascale-storage2016sc, daos-intro2020, daos-dram-intro2023, daos-github}. Beyond replacing POSIX file abstractions with key-value object stores, DAOS is a promising candidate for next-generation distributed storage systems, especially in high-performance computing (HPC) and large language model (LLM) environments \cite{hdf5-daos2022tpds, daos-adios2024ISC, hpc-weather2023ipdps, mei2024sc-poster, daos-perf-explore2024scw, daos-smartnic2025scw}.
In the latest IO500 Production list (ICS26), 2 of the top-5 storage systems run DAOS \cite{io500-ics26}.

Since the initial deployment in 2020, several prior works have studied DAOS's performance \cite{daos-intro2020, daos-vs-lustre2022pdsw, daos-dram-intro2023, daos-arm2023SCAsia, daos-scalability2023SCAsia, daos-perf-explore2024scw, DAOS-aurora-20-node-test2024scw, mei2024sc-poster, daos-smartnic2025scw}. 


\textcolor{blue}{
Benchmarking objectives.
In this paper, we present a comprehensive performance benchmark of DAOS, evaluating its I/O throughput, latency, and scalability under various workloads and configurations. We compare DAOS with traditional storage systems to highlight its advantages and identify potential bottlenecks. Our results demonstrate that DAOS can significantly improve I/O performance in HPC and LLM applications, making it a compelling choice for future storage solutions.
