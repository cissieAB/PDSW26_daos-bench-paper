\section{Introduction}

Distributed Asynchronous Object Storage (DAOS) is a high-performance, open-source parallel I/O stack built on Non-Volatile Memory Express (NVMe) and Remote Direct Memory Access (RDMA) technologies \cite{daos-exascale-storage2016sc, daos-intro2020, daos-dram-intro2023, daos-github}. Its underlying design of shifting from POSIX standards to key-value object store makes it a promising candidate for next-generation distributed storage systems, especially in high-performance computing (HPC) and large language model (LLM) environments \cite{hdf5-daos2022tpds, daos-adios2024ISC, hpc-weather2023ipdps, mei2024sc-poster, daos-perf-explore2024scw, daos-smartnic2025scw}.
